# Quick Task Plan

## Goal

Turn the guide contents list into useful reading wayfinding: preserve native
section links without JavaScript, show the current section while scrolling, and
make the contents available before the article on narrow screens.

## Tasks

1. Build a progressively enhanced guide-outline component with deterministic
   current-section selection, `aria-current="location"`, native hash links, and
   layout remeasurement.
2. Render a compact collapsible outline before mobile prose and the full
   current-section outline in the desktop sticky details rail; give the public
   starter article enough semantic structure for production-like acceptance.
3. Verify server fallback, direct hashes, scrolling, keyboard/touch, 320px
   overflow, accessibility, reading-size compatibility, and production build.

## Reference

- web.dev documents an always-available “On this page” list using a named
  `nav` and list semantics, with the table of contents moving between the
  article and sidebar across responsive layouts.
- GOV.UK navigation patterns use `aria-current` to distinguish the current
  location without removing ordinary links.
- Soji keeps native fragment navigation as the baseline and adds current
  section styling only after hydration.
