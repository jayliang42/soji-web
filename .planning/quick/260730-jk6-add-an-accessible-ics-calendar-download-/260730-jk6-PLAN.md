# Quick Task Plan

## Goal

Let readers download a standards-based calendar reminder for every valid
upcoming Office Hour without requiring a provider login or exposing protected
reservation and replay destinations.

## Tasks

1. Build deterministic RFC 5545 calendar-file generation with UTC start time,
   stable identity, escaped/folded text, bounded filename, and no invented
   session duration.
2. Add an accessible download control beside the existing upcoming-session
   actions, including success and unavailable feedback while retaining Copy as
   the manual fallback.
3. Verify calendar content, protected-link omission, browser-download
   behavior, page states, touch targets, accessibility, and production build.

## Reference

- Luma gives attendees individual iCalendar files so events can be added to
  personal calendar apps.
- Google Calendar imports individual `.ics` files.
- RFC 5545 permits a `VEVENT` with `DTSTART` and no `DTEND` or `DURATION`;
  Soji therefore records the known start without inventing a meeting length
  absent from the current content model.
