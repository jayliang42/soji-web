# Quick Task Plan

## Goal

Let readers build a lightweight, no-login reading list from Library cards and
article details, then return to it through a dedicated Saved filter. Keep the
preference on the current device and fail clearly when browser storage is not
available.

## Tasks

1. Add bounded, versioned saved-guide storage helpers and a synchronized,
   accessible Save control.
2. Integrate saving into guide cards and article details, plus a Saved Library
   focus with loading, empty, reset, reload, and Back/Forward behavior.
3. Verify persistence, cross-component synchronization, mobile layout,
   accessibility, and the production build before atomic GSD commits.

## Reference

- Medium exposes Save on stories and returns saved stories through its Library.
- Substack exposes a Saved reading-queue filter for posts readers want to
  prioritize.
- Soji's MVP remains local-only: guide slugs stay on the current device and no
  account, provider, or analytics write is introduced.
